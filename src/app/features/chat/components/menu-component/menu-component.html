Sobre o Mono

Mono é uma aplicação de chat alimentada por IA que oferece uma experiência conversacional rica e inteligente. O sistema integra dois modelos de IA, possui transcrição de áudio em tempo real, geração de resumos automáticos e um sistema robusto de gerenciamento de usuário, sistema voz personalizável, text-to-speech nas mensagens, e muito mais. O Mono é projetado para fornecer respostas rápidas e precisas, tornando a interação com a IA mais natural e eficiente.

Como funciona a IA?

Atualmente, o projeto contém duas IA's presentes, gpt-oss-20b e qwen2.5:0.5b. O gpt-oss-20b roda por meio de uma api disponibilizada pelo Groq Cloud, enquanto o qwen2.5:0.5b é executado server-side através do Ollama. Quer saber mais sobre essas IA's? Acesse os links abaixo:

Uma das partes pricipais do Mono é a utilização de TSS (text-to-speech) para leitura das mensagens, e para isso usamos o Pipper, ferramenta 100% código livre e feita com Python.
