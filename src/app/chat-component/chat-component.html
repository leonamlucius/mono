Mono é um chatbot de inteligência artificial para ajudar no dia a dia, desenvolvido com uma interface moderna e reativa em Angular e um backend robusto em Spring Boot

Utilizando o Spring AI para orquestração de dados, o projeto adota uma arquitetura híbrida de modelos: consome a infraestrutura da Groq para inferência ultrarrápida em nuvem utilizando o gpt-oss-20b, e integra o qwen2.5:0.5b localmente através do Ollama. Essa combinação entrega respostas fluidas com baixíssima latência, unindo a robustez do ecossistema Java à agilidade dos modelos de linguagem de última geração.
